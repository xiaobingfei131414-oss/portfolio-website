# 交互式 3D 作品集重设计规格

## 目标

参考 Lusion 的沉浸感与交互节奏，重设计现有电商 3D 视觉设计师作品集。网站应大胆、跳脱、醒目，同时通过统一的颜色、圆角、排版和运动曲线保持高级感。交互服务于作品浏览，不复制 Lusion 的品牌视觉，也不引入 WebGL 或动画框架。

## 视觉系统

- 主色：电光蓝 `#3147ff`、酸性绿 `#c8ff28`、暖白 `#f2f0e9`、深黑 `#11120f`。
- 章节以四种主色轮换，酸性绿仅用于关键动作与反馈，避免平均铺满。
- 使用超大无衬线标题、错位栅格、胶囊按钮、圆角画框和少量银灰材质。
- 项目图片保持主角地位，装饰图形不得遮挡作品主体或关键信息。

## 统一动效语言

- 自定义圆形光标：普通状态为小圆点，经过可交互元素时扩张并显示动作提示。
- 磁吸按钮：桌面端根据指针位置产生小幅位移，离开后弹性归位。
- 滚动揭示：标题、正文和图片使用同一组缓动与持续时间；图片以遮罩揭幕。
- 点击涟漪：导航、筛选和主要按钮共享圆形扩散反馈。
- 视差与倾斜：只用于主视觉、Showreel、项目卡片和个人照片，幅度受限。
- 阅读进度：页面顶部显示细线进度条。
- `prefers-reduced-motion: reduce` 下禁用跟随、倾斜、视差、平滑滚动和复杂转场。

## 分区设计

### 导航

- 桌面端使用悬浮胶囊容器；滚动后缩小内边距并增强背景模糊。
- 链接悬停时上下两层文字翻转；联系按钮使用酸性绿并带磁吸反馈。
- 移动端继续使用全宽展开菜单，并添加点击涟漪和分项进场。

### 首页

- 首屏切换为电光蓝背景，使用超大错位标题和暖白文字。
- Showreel 封面作为可交互主视觉，根据鼠标产生受限景深位移。
- 首屏文案、按钮和能力标签分层进入；交互不改变现有求职定位与信息顺序。

### Showreel

- 进入视口时使用圆角遮罩揭幕。
- 画面随指针轻微透视倾斜；播放按钮在画面内磁吸跟随。
- 点击播放使用圆形扩散反馈。无真实视频源时仍显示“示例视觉”提示，不伪装成可播放成片。

### 3D 作品与分类

- 卡片改为大小错落的编排，但阅读顺序保持从左到右、从上到下。
- 悬停时图片放大、卡片轻微倾斜，项目标题与职责从底部滑入。
- 分类按钮保留现有语义，切换时卡片淡出并弹性重排；筛选结果继续由现有数据源驱动。
- 点击卡片时以卡片中心为起点扩散遮罩，再打开案例弹窗。

### 核心能力

- 使用横向超大文字轨道表达建模、材质、渲染、动画。
- 页面纵向滚动驱动轨道缓慢横移，前后层方向相反。
- 详细说明保持静态可读，不依赖动画才能获取信息。

### 视觉作品

- 平面、摄影、绘画变为可拖拽的横向作品带。
- 卡片使用电光蓝、酸性绿、暖白与深黑轮换；拖拽后自动吸附最近卡片。
- 支持鼠标滚轮、触摸滑动和键盘浏览；点击仅做大图预览，不创建独立详情页。

### 关于与联系

- 个人照片随指针产生轻微偏转；履历按行进入视口。
- 联系区使用酸性绿整屏背景与超大邮箱文字。
- 邮箱悬停使用多层文字错位，保持链接可复制、可聚焦和可直接点击。

## 技术与性能

- 保持现有原生 HTML、CSS、JavaScript 架构，不增加依赖。
- 使用 CSS transforms、IntersectionObserver、requestAnimationFrame 和 Pointer Events。
- 指针跟随只在支持精确指针且未启用减少动态效果的设备上运行。
- 所有逐帧动画只修改 `transform`、`opacity` 或 CSS 自定义属性。
- 事件监听使用同一初始化入口；离开页面无需保留动画状态。
- 移动端不启用自定义光标、磁吸或 3D 倾斜。

## 验收标准

- 导航、首屏、Showreel、作品分类、能力、视觉作品、关于与联系均具有明确但统一的交互反馈。
- 桌面端鼠标移动、悬停、点击和滚动均能触发对应反馈，没有明显卡顿。
- 分类筛选、案例弹窗、移动导航、简历下载和联系方式保持可用。
- 键盘用户能够访问导航、筛选、项目卡片、案例弹窗和联系链接。
- 390px 宽度下无横向页面溢出；视觉作品带自身可横向滚动。
- 减少动态效果模式下内容完整、布局稳定、功能可用。
- 没有添加博客、WebGL、第三方动画库、虚构项目或虚构业务数据。
